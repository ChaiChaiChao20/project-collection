# ChaiChaiChao20 — project collection

Seven runnable project folders are published as separate public repositories. Start with each repository's README for setup and limitations.

| Project | Repository | Scope |
|---|---|---|
| Campus Sensor Monitoring and Alerts — GDG Backend Task 1 | [campus-signal-api](https://github.com/ChaiChaiChao20/campus-signal-api) | FastAPI + SQLite backend, rule CRUD, batch ingestion, alerts, simulator and measured load report. |
| WaferGuard — GDG AI/ML Task | [wafer-guard](https://github.com/ChaiChaiChao20/wafer-guard) | Corrected notebook, causal pipeline, trained artifacts, audit and inference CLI. See the metrics caveat in `AUDIT.md`. |
| EduSense AI — student analytics prototype | [edusense-ai](https://github.com/ChaiChaiChao20/edusense-ai) | Browser-based face/pose inference for local camera/video, aggregate trends, privacy boundaries and JSON export. The source proposal had no labeled data or code; this is a functioning research prototype, not a validated cognitive or engagement classifier. |
| Echo-Maze rover | [echo-maze-rover](https://github.com/ChaiChaiChao20/echo-maze-rover) | Curated source snapshot with ESP32 firmware, perception, telemetry/ML, dashboard, docs and baseline assets. See `ORIGIN_AND_ATTRIBUTION.md` for source provenance. |
| ESP32 priority-vehicle traffic light | [esp32-priority-traffic-signal](https://github.com/ChaiChaiChao20/esp32-priority-traffic-signal) | Two ESP32 sketches, ultrasonic/RF link and wiring/upload notes. Educational tabletop prototype. |
| Adaptive headlight | [adaptive-headlight](https://github.com/ChaiChaiChao20/adaptive-headlight) | Arduino Uno sketch and Wokwi relay/photoresistor diagram with hysteresis. Not a road-ready automotive controller. |
| AtmosRain-X | [atmosrain-x](https://github.com/ChaiChaiChao20/atmosrain-x) | Standalone interactive browser prototype; README identifies simulated effects. |
